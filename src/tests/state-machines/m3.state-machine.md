# M3

Workflow machine. Tracks a labelled process through its lifecycle.
Requires `M1 active` and coordinates with `M2`.

## States

- `M3 pending`: Workflow has not yet been started.
  - `A4` = 0
- `M3 open`: Workflow is actively progressing.
  - `A4` > 0
- `M3 paused`: Workflow is temporarily suspended.
- `M3 closed`: Workflow has ended, either completed or aborted.

Initial state: `M3 pending`

## Data

- `A3`: The label assigned to this workflow instance.
- `A4`: The progress score accumulated during the workflow.

Example values:

| `A3` | `A4` |
|------|------|
| `P1` | 0    |
| `P2` | 10   |
| `P3` | 20   |

## Transitions

### Default preconditions

- `M1 active`: Workflow operations require M1 to be active.

### Rules

| #   | States                                                | Trigger                  | Result                                    | Notes                                          |
|-----|-------------------------------------------------------|--------------------------|-------------------------------------------|------------------------------------------------|
| 012 | `M2 partial`, `M3 pending` with `A4` = 0              | `E5` with `A3`           | `M3 open` with `A3` and `A4` = 10        | Starting the workflow assigns label and score  |
| 013 | `M3 open`                                             | `E6`                     | `M3 paused`                               |                                                |
| 014 | `M3 paused`                                           | `E7`                     | `M3 open`                                 |                                                |
| 015 | `M3 open`, `M2 full`                                  | `E8`                     | `M3 closed` with `A4` = 20               | Completion requires full M2; score set to max  |
| 016 | `M3 open`, `M2 empty`                                 | `E9`                     | `M3 closed` with `A4` = 0                | Abort from open with empty counter             |
| 017 | `M3 paused`                                           | `E9`                     | `M3 closed` with `A4` = 0                | Abort while paused                             |
| 018 | `M3 open`                                             | `M1 inactive`             | `M3 paused`                               | Auto-paused when M1 deactivates                |
| 019 | `M1 inactive`, `M3 paused`                            | `M1 active` with `A1`    | `M3 open`                                 | Auto-resumed when M1 reactivates               |

### Impossible

| States       | Trigger          |
|--------------|------------------|
| `M3 closed`  | `E5` with `A3`   |
| `M3 closed`  | `E6`             |
| `M3 closed`  | `E7`             |
| `M3 closed`  | `E8`             |
| `M3 closed`  | `E9`             |
| `M3 pending` | `E6`             |
| `M3 pending` | `E7`             |
| `M3 pending` | `E8`             |
| `M3 pending` | `E9`             |

### Irrelevant

| States       | Trigger |
|--------------|---------|
| `M3 pending` | `E2`    |
| `M3 open`    | `E2`    |
| `M3 paused`  | `E2`    |
| `M3 closed`  | `E2`    |

### Notes

- Rule 019 explicitly overrides the default precondition by listing `M1 inactive` in the
  States cell: M3 resumes when M1 transitions back to active from inactive.
- E2 is the direct deactivation event for M1. M3 responds to the resulting state
  `M1 inactive` (rule 018) rather than to E2 itself; hence E2 is declared irrelevant
  across all M3 states.
