# M2

Counter machine. Counts items from 0 to 3. Requires `M1 active` to operate.

## States

- `M2 empty`: No items are counted.
  - `A2` = 0
- `M2 partial`: Some items are counted, below the maximum.
  - `A2` > 0
- `M2 full`: The maximum item count has been reached.
  - `A2` = 3

Initial state: `M2 empty`

## Data

- `A2`: The current item count.

Example values:

| `A2` |
|------|
| 0    |
| 1    |
| 2    |
| 3    |

## Transitions

### Default preconditions

- `M1 active`: Counter operations are only valid while M1 is active.

### Rules

| #   | States                         | Trigger       | Result                                      | Notes                               |
|-----|--------------------------------|---------------|---------------------------------------------|-------------------------------------|
| 004 | `M2 empty` with `A2` = 0       | `E3`          | `M2 partial` with incremented `A2`          |                                     |
| 005 | `M2 partial` with `A2` < 2     | `E3`          | `M2 partial` with incremented `A2`          |                                     |
| 006 | `M2 partial` with `A2` = 2     | `E3`          | `M2 full` with `A2` = 3                     | Ceiling reached                     |
| 007 | `M2 partial` with `A2` > 1     | `E4`          | `M2 partial` with decremented `A2`          |                                     |
| 008 | `M2 partial` with `A2` = 1     | `E4`          | `M2 empty` with `A2` = 0                   |                                     |
| 009 | `M2 full` with `A2` = 3        | `E4`          | `M2 partial` with decremented `A2`          |                                     |
| 010 | `M2 partial`                   | `M1 inactive` | `M2 empty`                                  | Counter cleared when M1 deactivates |
| 011 | `M2 full`                      | `M1 inactive` | `M2 empty`                                  | Counter cleared when M1 deactivates |

### Impossible

| States        | Trigger |
|---------------|---------|
| `M1 inactive` | `E3`    |
| `M1 inactive` | `E4`    |
| `M2 full`     | `E3`    |
| `M2 empty`    | `E4`    |

### Notes

- `A2` is always in the range [0, 3].
- Rules 010 and 011 fire as a state trigger when M1 transitions to `M1 inactive`.
