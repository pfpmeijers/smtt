# M1

Base machine. Tracks whether a named session is active.

## States

- `M1 inactive`: M1 has not been started or has been stopped.
- `M1 active`: M1 is currently running, identified by an `A1` value.

Initial state: `M1 inactive`

## Data

- `A1`: The identifier associated with the active M1 instance.

Example values:

| `A1` |
|------|
| `V1` |
| `V2` |

## Transitions

### Default preconditions

None

### Rules

| #   | States                        | Trigger                         | Result                              | Notes                                        |
|-----|-------------------------------|---------------------------------|-------------------------------------|----------------------------------------------|
| 001 | `M1 inactive`                 | `E1` with `A1`                  | `M1 active` with `A1`               |                                              |
| 002 | `M1 active` with `A1`         | `E1` with different `A1`        | `M1 active` with different `A1`     | Re-activation under a different identifier   |
| 003 | `M1 active`                   | `E2`                            | `M1 inactive`                       |                                              |

### Impossible

| States        | Trigger         |
|---------------|-----------------|
| `M1 inactive` | `E2`            |

### Notes

- E1 with the same `A1` already in use is a no-op and is not modelled.
